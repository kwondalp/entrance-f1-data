# Rankings contracts v1

`value/v1/manifest.json` and `power/v1/manifest.json` are independent approved current pointers. They reference immutable `release.<full-sha256>.json` payloads with exact byte sizes. The JSON schemas are in `schemas/`; Tools' `scripts/validate_rankings.py` also validates identities, ranks, coverage, lineage and hash bindings. Existing Archive, Profiles, Stats and current-season files remain unchanged.

The owner approved the current-season Value formula, salary input and descriptive Power publication in approval.v1.json. Production clients consume only these approved pointers. Technical verification, model validation, owner approval, workflow execution and hosting deployment remain separate evidence. Unsupported ability decompositions are still withheld.

Value: all official 2026 season participants through 6 September, with the owner's `participant-base-salary-v3` annual USD base-salary / championship-points definition and `annual-base-usd-v3` editorial selection. Salary estimates are sourced and effective-dated; range treatment and previous-season exceptions remain explicit. Zero points and missing or incomparable salary have null score/rank. No prorating or currency conversion occurs. Competition ties use exact ratios before display rounding.

Power: actual 2026 rounds 1–13 through 6 September, with 24 driver/car combinations and eight ranked measurements, `matched-race-pace-v1` / `gp-median-baseline-v1`. The score is a descriptive conditional log-lap-time gap in percentage points, lower faster. It is neither a probability nor driver ability. Five eligible GPs and the fixed GP-bootstrap interval-width gate are needed for a rank. Per-GP observations remain separate from release scores. Unsupported Driver, Car and Overall decomposition stays withheld. The current-season diagnostic does not validate a driver-ability predictor. Historical development payloads remain in the retained feature evidence and are not copied into this production contract.

Reference populations are fixed by the declared release selection; ordinary filters cannot renumber them. Each row carries a stable canonical identity and a safe display token. Methodology/reference/model/configuration versions, season/event/cutoff, UTC generation clock, input bindings and producer digest are present. Unknown source publication times are null. Retrospectively retrieved historical timing does not establish contemporaneous knowledge.

Each payload's `lineage` names the previous release and distinguishes correction, evidence advance and methodology change. Movement is valid only for compatible advancing evidence, never same-cutoff corrections. Older immutable releases listed by the pointer remain available. Empty successful releases are forbidden; a failed update preserves the last valid pointer. The browser re-verifies cached bytes and displays a stale notice when the newest request fails.

The current-season producer discovers only the verified sporting prefix, acquires at most three new/corrected GPs per invocation and reuses checksum-bound raw evidence. An OpenF1 live-session gate defers acquisition and cannot block independent Value calculation. Exact canonical names or published aliases bind timing numbers when Archive intentionally omits car numbers; no official sporting field is patched. See Tools `docs/rankings-current-season-automation.md`. Candidate execution, a manual workflow, an actual scheduled run and production activation are separate evidence states.

Raw OpenF1 timing is not redistributed here. Source URLs and hashes identify the research input. Derived Power material retains attribution to [OpenF1](https://openf1.org/) and its stated non-commercial/share-alike source terms; the repository's general code licence does not grant additional underlying timing rights. See Tools `docs/rankings-implementation.md` for source policy, acquisition, joins, exclusions, evaluation and operational commands. Value's estimated salary evidence is attributed to RacingNews365 in each row. The owner approved the stated derived-data scope; this does not grant additional upstream rights or permit raw timing redistribution.
